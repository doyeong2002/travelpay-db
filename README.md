# 해외여행 다통화 환전·결제 데이터베이스

수업 팀 프로젝트에서 트래블카드 서비스의 데이터 구조와 조회 기능을 설계했습니다. 실제 금융 서비스나 결제 시스템이 아닌 학습용 프로토타입입니다.

## 내가 맡은 작업

- 사용자, 원화 계좌, 외화 지갑, 트래블카드, 거래 내역의 다섯 테이블 관계 설계
- 기본키·외래키와 잔액·금액 제약조건 적용
- 계좌 잔액, 통화별 지갑 잔액, 카드 거래 내역, 통화별 지출, 가맹점별 결제 현황, 만료 예정 카드 조회 SQL 작성
- Flask 화면에서 검색 조건에 따른 조회 결과 확인

Flask 소스 코드는 현재 이 저장소에 포함하지 않았습니다. 이 저장소는 DB 설계와 SQL을 보여줍니다.

## 기술

MySQL, SQL, Flask

## 파일

- `schema.sql`: 다섯 테이블과 관계, 제약조건
- `sample_data.sql`: 실행 확인을 위한 가상의 예시 데이터
- `queries.sql`: 보고서에서 다룬 여섯 가지 조회 질의

## 실행

MySQL 8 환경에서 다음 순서로 실행합니다.

```bash
mysql < schema.sql
mysql < sample_data.sql
mysql < queries.sql
```

공개용 파일에서는 원본 과제에 있던 이름·연락처·계좌번호·카드번호 예시를 가상 값으로 바꾸고, 카드 보안정보를 저장하는 필드를 제거했습니다. 따라서 이 저장소는 제출본의 개인정보 예시를 제거해 다시 구성한 버전입니다. 환전·결제 잔액을 갱신하는 업무 로직은 포함하지 않습니다.
